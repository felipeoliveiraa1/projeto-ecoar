# Projeto ECOAR — Agente de IA do Método RB7

Código do agente de IA do Método RB7 (Escola Plano Ecoar).

- `web/`: aplicação Next.js (interface de chat, API e agentes em LangGraph). Instruções em `web/README.md`.
- `scripts/`: ferramentas de preparação da base de conhecimento (legendas → transcrições → trechos, verificação de citações).

O conteúdo do curso não faz parte deste repositório. Ele fica na base de conhecimento (Supabase) e em arquivos locais.
